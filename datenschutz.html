🌐 Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website werden technisch notwendige Verbindungsdaten an GitHub übertragen. Dazu können insbesondere IP-Adresse, Datum und Uhrzeit des Zugriffs, aufgerufene Inhalte, Browserinformationen und technische Protokolldaten gehören.

Weitere Informationen zur Datenverarbeitung durch GitHub findest du in der Datenschutzerklärung von GitHub.

🎮 Minecraft-Spielernamen und Whitelist

Auf der Spielerseite können Minecraft-Benutzernamen von für den Server freigeschalteten Spielern angezeigt werden. Diese Angaben dienen der Organisation und transparenten Darstellung der HalfKnife-SMP-Community.

Ein Spieler kann jederzeit darum bitten, dass sein Benutzername von der öffentlichen Website entfernt wird. Die Kontaktaufnahme ist über Discord möglich.

🟢 Online-Status

Die Website kann anzeigen, welche Minecraft-Benutzernamen aktuell mit dem HalfKnife-SMP-Server verbunden sind. Die dafür verwendeten Serverdaten werden automatisiert bereitgestellt und ausschließlich zur Anzeige des aktuellen Serverstatus verwendet.

🔗 Externe Links

Die Website enthält Links zu externen Diensten wie Discord und Modrinth. Erst beim Anklicken eines solchen Links wird die jeweilige externe Website aufgerufen. Für die dortige Datenverarbeitung gelten die Datenschutzbestimmungen des jeweiligen Anbieters.

🍪 Cookies und Tracking

HalfKnife SMP 2026 setzt nach aktuellem Stand keine eigenen Analyse-, Werbe- oder Tracking-Cookies ein. Auf dieser Website sind derzeit keine externen Analyse-Dienste wie Google Analytics eingebunden.

📁 Speicherdauer

Öffentlich angezeigte Minecraft-Benutzernamen werden grundsätzlich nur so lange angezeigt, wie dies für die Organisation der jeweiligen Server-Season erforderlich ist oder bis eine Entfernung verlangt wird. Technische Protokolldaten des Hostings werden nach den Vorgaben des jeweiligen Hostinganbieters verarbeitet und gelöscht.

Soweit personenbezogene Daten verarbeitet werden, bestehen nach Maßgabe der DSGVO insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und gegebenenfalls Widerspruch. Außerdem besteht das Recht, sich bei einer zuständigen Datenschutzaufsichtsbehörde zu beschweren.
