Die größten Neuerungen

Diese Features werden die neue Season prägen.

🎒

Backpacks

Zusätzlicher Stauraum, zahlreiche Upgrades und sogar ein tragbarer Crafting-Bereich.

🌕

Mondphasen

Blood Moon, Harvest Moon, Blue Moon und weitere besondere Nächte verändern die Welt.

⚔️

RPG-System

Skillpunkte, Attribute und ein eigener Charakterfortschritt begleiten dich durch die Season.

Voice Chat

Kommunikation direkt im Spiel.

🎙️ Instant Groups

Fügt automatisch alle Spieler in deiner Nähe einer Gruppe hinzu.

/instantgroup

🔄 Auto Join

Automatischer Beitritt zu einer festgelegten Gruppe.

/autojoingroup set <gruppe>

👥 Permanente Gruppen

Dauerhafte Gruppen für Teams und Projekte.

/persistentgroup list

Weitere Features

Die wichtigsten Mods kurz erklärt.

🔒 Chest Locker

Schütze Kisten, Fässer und Container vor fremdem Zugriff.

⚡ Better Tridents

Überarbeitete Dreizacke, neue Reparaturmöglichkeiten und zusätzliche Funktionen.

⚰️ Grabsteine

Verlorene Items verschwinden nicht, sondern werden sicher gespeichert.

🌍 End & Nether

Beide Dimensionen wurden massiv erweitert und bieten deutlich mehr zu entdecken.

📦 Lootr

Jeder Spieler erhält seinen eigenen Loot aus Truhen.

🏠 Neue Baumöglichkeiten

Viele zusätzliche Blöcke, Möbel und Dekorationen.

Wichtige Befehle

Die wichtigsten Commands im Überblick.

🎙️ Voice Chat

/instantgroup

Erstellt automatisch eine Gruppe mit Spielern in deiner Nähe.

/persistentgroup list

Zeigt alle permanenten Gruppen.

/autojoingroup set <gruppe>

Automatischer Gruppenbeitritt.

🔒 Chest Locker

/scl lock

Container sperren.

/scl unlock

Container entsperren.

/scl trust <spieler>

Spieler freigeben.

/scl players

Berechtigte Spieler anzeigen.

🛒 Easy Shop

/shop create

Eigenen Shop erstellen.

/shop close

Shop schließen.

/shops

Alle Shops anzeigen.

/shop recover

Shop-Inhalte wiederherstellen.

🎒 Backpack

B

Ausgerüsteten Backpack öffnen.

Equip

Rucksack auf dem Rücken anlegen.

Back Slot

Backpack sichtbar tragen.
