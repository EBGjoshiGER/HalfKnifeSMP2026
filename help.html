VoiceChat – Gruppen

Instant Groups

Der Befehl /instantgroup fügt automatisch alle Spieler in der Nähe zu einer Gruppe hinzu.

Standardreichweite: 128 Blöcke – alternativ: /instantgroup 256

Gruppenübersicht

Spieler erhalten beim Joinen eine Übersicht aller aktiven Gruppen.

Persistente Gruppen

/persistentgroup list
/persistentgroup remove <name>
/persistentgroup remove <id>
/persistentgroup add <name> [<normal|open|isolated>] [<hidden>] [<password>]

Auto Join

/autojoingroup set <gruppe> [passwort]
/autojoingroup remove

/autojoingroup global set <gruppe>
/autojoingroup global remove
/autojoingroup global force <true|false>
