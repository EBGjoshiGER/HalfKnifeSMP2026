Easy Shop

```

Mit Easy Shop kann jeder Spieler einen eigenen Shop erstellen und mit anderen Spielern handeln.

Shop erstellen

/shop create

Erstellt einen persönlichen Shop und spawnt einen eigenen NPC mit dem Namen [Spielername]'s Shop.

  • Der NPC bewegt sich nicht
  • Der NPC ist unverwundbar
  • Pro Spieler kann nur ein Shop erstellt werden
  • Angebote und gelagerte Items bleiben dauerhaft erhalten

Shop schließen

/shop close

Schließt den eigenen Shop und entfernt den NPC aus der Welt. Alle Angebote und gelagerten Items bleiben erhalten. Der Shop kann später jederzeit wieder geöffnet werden.

Shops anzeigen

/shops

Öffnet eine Übersicht aller verfügbaren Shops inklusive der Anzahl ihrer aktiven Angebote.

Items wiederherstellen

/shop recover

Falls ein Shop gelöscht wurde, können mit diesem Befehl alle darin gespeicherten Items zurückgeholt werden.

  • Alle Items aus den Shop-Angeboten
  • Alle Items aus dem Shop-Lager
  • Keine Items gehen durch das Löschen eines Shops verloren
```

Mondphasen

```

Bestimmte Mondphasen bringen besondere Ereignisse und verändern die Welt für eine Nacht.

Blood Moon

Der Himmel färbt sich rot und riesige Horden von Untoten erscheinen. Während einer Blood Moon Nacht ist die Anzahl der Untoten deutlich erhöht.

Wenn der Mond besonders groß erscheint, wird die Nacht noch gefährlicher – bleibt besser drinnen!

Blue Moon

Eine besonders glückliche Nacht. Beim Minen besteht eine erhöhte Chance, auf verlassene Minenschächte zu stoßen.

Auch beim Angeln könnt ihr mehr Glück haben und besondere Fänge machen. Ein besonders großer Mond verstärkt den Effekt.

Harvest Moon

Die perfekte Nacht für eure Farmen. Während einer Harvest Moon fällt eure Ernte besonders großzügig aus.

Je größer der Mond erscheint, desto größer fällt auch die Ernte aus.

Super Moon

Heute wird es schleimig! Während einer Super Moon wird die Welt von deutlich mehr Slimes bevölkert.

```

Backpacks

```

Backpacks bieten zusätzlichen Stauraum und können unterwegs oder auf dem Rücken verwendet werden.

Benutzung

  • In der Haupthand halten und Rechtsklick drücken, um den Rucksack zu öffnen
  • Über den Button Equip im Backpack-GUI kann der Rucksack auf dem Rücken ausgerüstet werden
  • Ein ausgerüsteter Rucksack kann standardmäßig mit B geöffnet werden
  • Durch die Curios/Trinkets/Accessories-Kompatibilität wird der Rucksack im Back-Slot getragen
  • Backpacks können als Block in der Welt platziert werden
  • Platzierte Backpacks können über Hopper und Pipes automatisiert befüllt und entleert werden
  • Ausgerüstete Backpacks werden sichtbar auf dem Rücken des Spielers dargestellt

Rucksack-Stufen

Es gibt insgesamt fünf verschiedene Rucksack-Stufen:

  • Leather
  • Iron
  • Gold
  • Diamond
  • Netherite

Mit jeder höheren Stufe erhält der Rucksack mehr Stauraum sowie zusätzliche Upgrade- und Werkzeugplätze.

Das Upgrade erfolgt an einem Schmiedetisch:

Leather Backpack + Tier Upgrade Item
```

→ nächsthöhere Backpack-Stufe
```

Funktionale Upgrades

Backpacks können mit zahlreichen verschiedenen Upgrades erweitert werden.

  • Tank – Flüssigkeiten speichern
  • Crafting – Crafting unterwegs ermöglichen
  • Feeding – automatische bzw. vereinfachte Versorgung mit Nahrung
  • Magnet – Items automatisch aufsammeln
  • Pickup – zusätzliche Möglichkeiten zum Aufnehmen von Items
  • Void – unerwünschte Items automatisch entfernen
  • Furnace – Items direkt im Rucksack verarbeiten
  • und weitere Upgrades

Weitere Funktionen

  • Schlafsack benutzen, ohne den Spawnpunkt zu verändern
  • Praktische Werkzeugplätze für schnellen Zugriff auf Tools
  • Hose-Item zur Verwaltung von Flüssigkeiten im Backpack
```
